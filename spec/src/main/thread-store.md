# 对话状态库

数据库连接延迟建立并复用，以只读方式打开 `state_5.sqlite`。列表只包含未归档的 exec 对话，按 `updated_at`、ID 降序取最多 300 条。

目录筛选是精确匹配；搜索去掉首尾空白后，以 SQLite LIKE 同时匹配标题、首条用户消息和名字。参数使用绑定值；关键词中的 `%`、`_` 仍具有 LIKE 通配含义。

标题依次取名字、标题、首条用户消息，截取首行并限制为 120 个字符。时间优先取毫秒列，缺失时将秒列乘以 1000。缺失模型、推理档位保留为 null，缺失 token 用量为 0。

按 ID 获取对话不限制来源或归档状态。列表变化指纹只包含 exec 未归档记录的数量及最大更新时间，不能识别所有不改变这些汇总值的修改。最近目录包含所有来源的未归档记录，按目录最近更新时间排序。
