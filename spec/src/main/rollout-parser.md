# Rollout 时间线解析

解析器逐行接收 JSONL，跳过空行和无法解析的 JSON；时间戳无效时使用当前时间。出现 `item_completed` 后展示新格式条目，否则使用 `response_item` 旧格式兜底。

新格式支持用户消息及图片路径、agent 回复及阶段、可读推理摘要、命令输出、文件 diff、MCP 参数与结果、图片路径、上下文压缩。未知条目使用通用类型和 JSON 详情；没有可读内容的推理条目不显示。

命令输出和单文件 diff 超长时保留头尾各约一万字符，中间标注省略数量。MCP 参数、结果及通用详情的保留上限为约八千字符。shell 参数包装的命令展示内部命令，`file://` 前缀从路径中移除。

旧格式排除以环境、用户指令、AGENTS 或 permissions 标记开头的注入用户消息。工具调用先占位，再按 call ID 更新输出；这些调用统一表示为命令条目。

`task_started` 增加未结束回合计数，`task_complete` 或 `turn_aborted` 减少计数并生成结束条目。回合时长来自最近开始时间；`turn_context` 记录模型和档位。token_count 提供累计总量、输入、缓存输入、输出、上下文窗口及最近输入量。

只显示日志中可读的推理内容，不解密推理，也不在此解析层渲染图片。
