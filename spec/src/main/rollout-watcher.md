# Rollout 增量读取与订阅

每个文件缓存偏移、未结束行、解析状态和上次推送数量。读取只解析以换行结束的完整记录，未结束行留到后续读取。单个读取块最多 4 MiB，同次读取循环直到当前文件末尾，不限制整个 load 的总读取量。

文件大小小于偏移时重置解析状态；仅凭大小变化判断截断，不能保证发现所有同长度替换。文件 stat 失败时保留已有缓存。

订阅按路径引用计数；存在订阅时每 700 毫秒轮询，最后一个订阅取消后停止计时器。load 返回完整快照并记为已推送；peekRunning 刷新读取，current 只读取缓存。

格式从旧变新或可见条目数量减少时推送整体替换，其余推送新增条目。旧格式工具结果可能原位更新，因此仅按条目数的增量不会覆盖所有既有条目变化。

未结束回合且文件最近 30 分钟有写入时视为运行中。缓存没有淘汰机制；UTF-8 按读取块独立解码，没有跨块多字节解码缓冲。
