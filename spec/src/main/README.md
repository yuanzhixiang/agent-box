# 主进程与本地 Codex

应用读取 `CODEX_HOME`，未设置时使用 `~/.codex`。SQLite 状态库以只读连接打开，rollout 和配置以文件读取方式访问；本应用不直接写这些文件。发起任务后的数据写入由 Codex CLI 完成。

| 数据     | 来源及口径                                                             |
| -------- | ---------------------------------------------------------------------- |
| 侧栏对话 | `state_5.sqlite` 的 `threads`，未归档且 `source = 'exec'`，最多 300 条 |
| 对话详情 | 按 ID 查询，不限定来源；内容来自记录中的 `rollout_path`                |
| 模型     | `models_cache.json` 中 `visibility = 'list'` 的模型                    |
| 默认设置 | `config.toml` 首个表之前的双引号字符串配置                             |
| 最近目录 | 所有来源的未归档对话，最多 15 个目录                                   |

数据库指纹每 2 秒检查一次。被订阅的 rollout 每 700 毫秒读取新增完整行。本应用的进程正在运行，或 rollout 有未结束回合且最近 30 分钟有写入时，对话显示运行中。

任务通过 `codex exec` 或 `codex exec resume` 执行，模型、推理强度、Fast 和权限设置只覆盖本次 CLI 调用，不修改用户配置。停止能力只管理本应用启动的进程。

窗口默认以 1060 × 700 逻辑像素居中打开，不自动最大化或全屏，最小尺寸为 900 × 600。窗口使用隔离的 preload 接口访问主进程。渲染进程没有 Node 集成；Electron sandbox 当前关闭。IPC 参数使用 TypeScript 接口约定，没有完整的运行时参数校验；模型和推理档位另有字符校验。
