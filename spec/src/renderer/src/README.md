# 界面与交互

界面采用白底、浅灰侧栏、Geist 正文字体与 Geist Mono 代码字体。左侧显示项目与会话，右侧显示新会话页或所选时间线；没有 URL 路由和选择持久化。

新会话页提供标题、欢迎语和底部输入框。详情页显示标题、项目、只读 Access Options、时间线和续问输入框。用户消息在灰底框中，agent 回复直接展示 Markdown，活动按独立行展开。

输入框工具栏保持单行，依次为附件、模型与推理档位、自主级别、工作模式、Connectors、Skills、快捷键帮助和右侧语音/发送/停止按钮。工作目录选择位于新会话输入框上方；错误与忙碌提示在工具栏外，避免挤出第二行。900、1050、1360 像素窗口宽度使用同一行布局。

本地模型列表和执行权限来自 Codex。Factory 标志及 Max Arden 账号标签用于当前界面展示，不构成 Factory 登录或账号关联。Connectors、Skills、Mission Mode 禁用；侧栏 Automations 显示未接入说明，Mission Control 仅列当前查询结果中的运行会话。

图片条目只显示路径。语音依赖运行时 SpeechRecognition 支持及服务可用性。其他进程启动的任务不能由本应用停止，显示运行中时输入框禁止续问。菜单和表单选择使用组件内状态，重新挂载后不保留自主级别或工作模式。

界面组件使用 Tailwind 工具类、条件类与后代变体实现样式；全局 CSS 只维护主题、字体及全局基础规则。组件行为不通过 CSS 类名定位 DOM。
