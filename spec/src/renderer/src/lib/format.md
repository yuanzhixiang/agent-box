# 展示格式

formatRelativeTime 使用中文相对时间：一分钟内“刚刚”，一小时内分钟，同一天显示时分，昨天加前缀，其他日期显示月日时分。formatClock 使用 zh-CN 24 小时时钟。

formatDuration 对 null 返回空串，一秒内显示 ms，一分钟内显示一位小数秒，其他显示分钟和四舍五入的秒。没有对秒数进位为 60 的额外归一化。

formatTokens 在千以下保留原值，千到百万显示一位小数 k，百万及以上显示一位小数 M。shortPath 对超过两段的路径仅保留最后两段并加省略前缀。侧栏的 now/m/h/d 是侧栏组件独立实现的时间口径。
