# 输入框与任务提交

Composer 支持新建和续问。目录按临时覆盖、会话目录、最近目录取值；模型按覆盖、会话、默认模型、首个缓存模型取值；推理档位按覆盖、会话/模型默认、首个支持档位回退。Fast 使用覆盖或本地默认值。

新建模式在框外提供原生目录选择，续问沿用会话目录。加号打开多文件选择，附件路径去重、显示文件名和移除按钮。输入框随内容在 42–240 像素内增高。

模型菜单提供本地可见模型、推理档位选择和支持时的 Fast 开关。切换模型使用新模型默认档位；不支持 Fast 的模型将临时 Fast 关闭。推理按钮循环支持档位，自主按钮循环 Low/Medium/High，初始 Low。

工作模式初始 Normal，可切换 Spec；权限映射见主进程 runner 规格。Mission Mode、Connectors、Skills 禁用，不提供伪执行结果。弹出菜单向上展开，支持上下键移动按钮焦点、点击框外关闭、Escape 关闭并恢复触发按钮焦点。

| 输入框快捷键 | 当前行为                                                          |
| ------------ | ----------------------------------------------------------------- |
| Enter        | 发送；输入法组字过程中不触发                                      |
| Shift+Enter  | 换行                                                              |
| Tab          | 循环推理档位                                                      |
| Shift+Tab    | 切换 Normal/Spec                                                  |
| Ctrl+N       | 打开模型菜单                                                      |
| Cmd/Ctrl+L   | 循环自主级别                                                      |
| Escape       | 停止当前本应用任务；空闲时连续两次且间隔小于 700ms 清空输入和附件 |

帮助弹层显示快捷键与模式说明，支持背景、关闭按钮、Escape 关闭，将 Tab 焦点限制在关闭按钮，并在关闭后恢复之前焦点。Cmd/Ctrl+K 的搜索行为由侧栏实现。

发送需要非空文本、目录、模型、推理档位，且没有正在提交、本应用活动任务或其他进程运行标记。提交时去掉文本首尾空白；IPC 接受后清空文本和附件，失败时保留并在框外显示错误。新任务取得 threadId 后切换详情。

右侧按钮优先显示正在听写的麦克风，其次本应用活动任务的停止按钮，再次非空输入的发送按钮，空输入显示语音按钮。检测不到 SpeechRecognition/webkitSpeechRecognition 时语音禁用。听写使用浏览器语言、连续识别且只接收最终结果，追加到输入；停止、结束或错误清除听写状态，卸载时 abort。

模型、权限、工作模式和附件不写入持久存储。组件重新挂载后覆盖状态重置；语音服务可用性和麦克风许可由运行时决定；目录选择异常没有单独的错误处理。其他进程任务只显示忙碌，不提供停止能力。

布局、颜色、状态与响应式样式使用 Tailwind 工具类及变体，不依赖自定义组件 CSS 选择器。

快捷键弹层通过 React ref 获取焦点容器，不通过样式类名定位 DOM。
