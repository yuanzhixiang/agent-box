# 会话标题栏

标题和 cwd 最后一段在同一行显示，完整值通过 title 提示。省略号按钮复制会话 ID，成功后提示 Copied；按钮不打开额外菜单，也不自动重置复制状态。

Access Options 按钮切换只读弹层，显示本地工作目录、模型、推理档位、运行状态和存在时的累计 token 数。该入口不修改任务权限；实际权限覆盖由 Composer 和 Runner 完成。

标题区域可拖动窗口，交互按钮排除拖动。Access 弹层只由自身按钮切换，没有外部点击或 Escape 关闭处理。

布局、颜色、状态与响应式样式使用 Tailwind 工具类及变体，不依赖自定义组件 CSS 选择器。
