# 消息条目

用户文本保留换行并置于灰底消息框，时间在悬停时显示。超过 14 行或 1500 字符时默认裁切为带渐隐的区域，可展开或收起。附图只显示路径文字。

agent 回复通过 MarkdownText 渲染，不增加头像或消息标题；commentary 使用更浅文字。推理内容置于默认关闭的 Thought process details 中。

turn_start 不显示；turn_end 显示结束或中断、时钟时间和存在时的用时，中断使用危险色；压缩条目显示上下文已压缩和时钟时间。其他活动由 ActivityGroup 处理。

布局、颜色、状态与响应式样式使用 Tailwind 工具类及变体，不依赖自定义组件 CSS 选择器。
