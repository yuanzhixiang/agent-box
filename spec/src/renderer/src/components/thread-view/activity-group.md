# 活动行与详情

活动组为每个条目显示独立折叠行，默认关闭；live 属性只写入 data-live，不自动展开。标题分别取命令、文件名、MCP server/tool/title、图片路径或通用标签。

命令非零退出显示 exit code，其他失败或拒绝显示对应状态；命令和 MCP 存在用时时显示时长。点击该行切换详情，并更新 aria-expanded。

命令详情显示 cwd、命令和输出，空输出有说明；文件详情显示类型、路径和按新增绿/删除红/块头灰着色的 diff；MCP 显示参数和结果；图片与通用条目显示路径或原始详情。

详情使用等宽字体及滚动区域，最大高度 24rem，不在 UI 重新执行命令、应用 diff 或渲染图片。

布局、颜色、状态与响应式样式使用 Tailwind 工具类及变体，不依赖自定义组件 CSS 选择器。
