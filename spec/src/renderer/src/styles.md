# 全局视觉与布局

样式加载 Tailwind，并使用本地 Geist 400/500/600/700 与 Geist Mono 400。界面白底、深色正文、灰色次要文字及细边框；代码与 pre 使用等宽字体。

应用顶部为原生标题栏保留 28 像素拖动区域。侧栏默认宽 260 像素，在窗口不宽于 1050 时宽 240 像素，折叠宽 52 像素。会话标题栏高 40 像素。

时间线内容最大宽 744 像素，输入框及工作目录、状态区域最大宽 736 像素。用户消息使用浅灰底、边框和小圆角，agent 消息没有气泡框。

工具栏高 44 像素且 flex-wrap 为 nowrap；控件文字单行，模型文本可收缩省略，提交按钮靠右。工作目录和状态行位于框外。较窄窗口减少间隔、字号及模型宽度，不把帮助或提交按钮移至第二行。附件列表单独允许换行。

菜单向上展开并限制高度，弹层使用遮罩和滚动区域。滚动条细化；prefers-reduced-motion 时关闭动画和过渡。

styles.css 仅包含 Tailwind 导入、@theme 主题、@font-face 字体注册，以及用 @apply 实现的全局基础、焦点、滚动条和减少动效规则。组件布局、状态、Markdown 排版及响应式规则直接放在 TSX 的 Tailwind 类中，没有自定义组件选择器或 @apply 组件封装。Electron 拖动区域使用 Tailwind 任意属性表达。
